Q2-a: اشتقاق معادلة Doppler Shift للرادار (5 درجات)

▼
المطلوب: اشتق معادلة الإزاحة الدوبلرية (Doppler Shift) للرادار.

الحل:
نبدأ بالموجة الكهرومغناطيسية المرسلة:
E(r,t) = E₀ × e^(j(ωt - kr))
حيث k = 2π/λ هو ثابت الانتشار (Propagation Constant)

في اتجاه x:
E(x,t) = E₀ × cos(2πf₀t - (2πf₀/c)x)

المسافة الكلية للإشارة = 2R (ذهاب وعودة)

التردد المستقبل fR = (1/2π)(dθ/dt)
fR = f₀(1 - 2v/c) = f₀ - 2vf₀/c

المعادلة النهائية:
f_R = f₀ ± 2v/λ

- علامة (-) لما الهدف بيبعد عن الرادار
- علامة (+) لما الهدف بيقرب من الرادار
- fd = 2v/λ = 2vf₀/c هي الإزاحة الدوبلرية

Q2-b: معادلة مدى الرادار (Radar Range Equation) (4 درجات)

▼
الخطوات:

1. Isotropic radiation: كثافة القدرة عند مسافة R:
P_di = P_t / (4πR²)

2. Directive Antenna: مع كسب الهوائي G:
P_dd = P_t × G / (4πR²)

3. Target Interception: القدرة المعترضة بواسطة الهدف (حسب RCS σ):
P_de = P_dd × σ / (4πR²)

4. Return Power: القدرة المستقبلة عند الرادار:
P_r = P_de × A_e

المعادلة النهائية:
R_max = [P_t × G² × λ² × σ / ((4π)³ × S_min)]^(1/4)

Q2-c: حساب Maximum Unambiguous Range لثلاث PRFs (6 درجات)

▼
المعادلة: R_unamb = c / (2 × PRF) حيث c = 3×10⁸ m/s

Mode 1: PRF = 500 Hz
R = 3×10⁸ / (2×500) = 3×10⁸ / 1000 = 300 km

Mode 2: PRF = 2000 Hz
R = 3×10⁸ / (2×2000) = 3×10⁸ / 4000 = 75 km

Mode 3: PRF = 5000 Hz
R = 3×10⁸ / (2×5000) = 3×10⁸ / 10000 = 30 km

المخاطر التشغيلية عند التبديل بين الأوضاع:
- Range ambiguity عند PRFs العالية
- Doppler ambiguity
- Trade-offs في SNR ودقة التتبع
- تعقيد المعالجة واحتمال فقدان استمرارية التتبع

Q3-a: حساب Doppler Frequency Shift و Phase Shift (5 درجات)

▼
المعطيات:
f_c = 10 GHz, v = 150 m/s, c = 3×10⁸ m/s, PRI = 1 ms

الخطوة 1: حساب Doppler Frequency Shift:
f_d = 2v × f_c / c = (2 × 150 × 10×10⁹) / (3×10⁸)
f_d = 10,000 Hz = 10 kHz

الخطوة 2: حساب Phase Shift:
Φ = 2π × f_d × PRI = 2π × 10000 × 1×10⁻³
Φ = 20π radians

Q3-b: حساب زاوية التوجيه لـ Phased Array (2 درجات)

▼
المعطيات:
N = 8 عناصر, d = λ/2, α = -2π/λ
β = -kd×cos(θ), k = 2π/λ

الحل:
α = (-2π/λ) × d = (-2π/λ) × (λ/2) = -π radians

β = α → -kd×cos(θ) = -π
-(2π/λ)(λ/2)cos(θ) = -π
-π×cos(θ) = -π
cos(θ) = 1

θ = 0° (broadside)

Q3-c: MTI Radar Block Diagram مع Power Amplifier (3 درجات)

▼
المكونات الأساسية في رادار MTI اللي بيستخدم Power Amplifier:

1. Pulse Modulator: بيتحكم في توقيت النبضات المرسلة
2. Power Amplifier: بيضخم الإشارة قبل الإرسال (التردد = f_l + f_c)
3. Duplexer: بيبدل بين الإرسال والاستقبال على نفس الهوائي
4. Stalo (Stable Local Oscillator): بيولد تردد مرجعي ثابت f_l - بيتصل بالـ Mixer في الإرسال والاستقبال
5. Mixer (إرسال): بيجمع تردد Stalo مع Coho لتوليد f_l + f_c
6. Mixer (استقبال): بيحول الإشارة المستقبلة (f_l + f_c ± f_d) إلى IF (f_c ± f_d)
7. IF Amplifier: بيضخم إشارة الـ IF
8. Coho (Coherent Oscillator): بيوفر إشارة مرجعية coherent عند التردد f_c
9. Phase Detector: بيقارن الإشارة المستقبلة مع إشارة Coho المرجعية - الخرج = f_d
10. Delay-Line Canceler: بيلغي إشارات الـ Clutter الثابتة ويمرر إشارات الأهداف المتحركة

الميزة الأساسية: استخدام Power Amplifier بدل Power Oscillator بيحافظ على الـ Coherence لأن الإشارة المرجعية بتيجي من Stalo و Coho مش من المذبذب نفسه.
